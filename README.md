# pokemarket-patriots

Plataforma de gestión, valoración y subastas de cartas Pokémon de colección — CE-1116

## ¿Qué es PokéMarket?

PokéMarket es una plataforma vertical para la gestión, valoración y transacción
de cartas Pokémon de colección. Opera como infraestructura de datos para el
segmento B2B (API de precios para tiendas y dealers) y como canal de compraventa
para el segmento B2C (subastas con descubrimiento de precio en tiempo real).

Su diferenciador es la taxonomía de identidad de la carta: edición, idioma,
acabado visual y grado de conservación certificado determinan el valor, con
diferencias de hasta 200 veces entre variantes que los marketplaces genéricos
no modelan.
